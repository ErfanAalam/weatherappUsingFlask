# Flask Project

## weather app based on openweather api where the data is fetched from the api and displayed on the screen

## Prerequisites
 - Phython should be installed (upgraded version)
 - Git Installed for cloning the project (optional)

# Installation

## Steps

 - Step 1 : create the virtaul environment using command in terminal
    command : python -m venv venv

 - Step 2 : Activate the virtual environment 
    .\venv\Scripts\activate

 - step 3 install the dependencies using command with the help of requirement.txt file
    pip istall -r requirements.txt

# setup is complete now run the flask using : flask run

and the project is run on the port http://127.0.0.1:5000/ || http://localhost:5000/
